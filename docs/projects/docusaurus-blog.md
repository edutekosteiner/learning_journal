This is where I'm working on my Docusaurus project, which will also be my first real Git project.


## Steps
This section lists the key steps required to set up the project, get it up and running, and then implement the requirements from the checklist.

1. Configure settings in your GitHub account.
   Project Settings\Pages\Build and Deployment\ -> Set 'Source' to 'GitHub Actions'
2. Cloning the template repository to your own GitHub account. https://github.com/Developer-Akademie-DevSecOpsKurs/dev-blog-template
3. Cloning the repository to the local computer.
```bash
git clone https://github.com/edutekosteiner/learning_journal
```
4. Set up npm
    1. Install npm.
   ```bash
   npm install
   ```
    2. Updates the installed npm packages.
   ```bash
   npm update
   ```
    3. Starting the npm project for local debugging
   ```bash
   npm start
   ```
5. Implementing the items on the checklist.
    1. Adapt based on the task.
    2. Verifying the Functional Change in the Application.
    3. Restart the application as needed to apply the changes.
      1. Cancel the application using the [Ctrl] and [C] keys.
      2. Starting the Application
      ```bash
      npm start
      ```
